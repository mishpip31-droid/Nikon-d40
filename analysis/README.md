# Полная карта функций прошивки D40 (A 1.11, B 1.11)

Получено собственным статическим анализатором `tools/frdis/` по оригинальным
файлам (SHA-256 совпадают с атласом v15). Код не исполнялся.

| Файл | Содержимое |
|---|---|
| `MAP_A.md`, `MAP_B.md` | Сводка: охват, распределение кода, частые функции, системные вызовы, периферия, строки |
| `*/functions.csv` | Все найденные функции: адрес, смещение, источник, размер, вызовы, вызовы ОС, достоверность |
| `*/callgraph.json` | Граф вызовов (вызывающая → вызываемые) |
| `*/xrefs.json` | Обращения к памяти/периферии по константным адресам и прямой I/O |
| `*/os_calls.json` | Системные вызовы `INT 0x40` по коду (r12) и функции, которые их делают |
| `*/strings.csv` | ASCII-строки и ссылающиеся функции |

Листинги (`listing.txt.gz`) в репозиторий не входят: они содержат байты прошивки
Nikon. Пересоздать:

```bash
python3 tools/frdis/analyze.py B firmware/BD400111.bin out/B [atlas/data/symbols.csv]
python3 tools/frdis/analyze.py A firmware/AD400111.bin out/A [atlas/data/symbols.csv]
python3 tools/frdis/report.py B out/B firmware/BD400111.bin > MAP_B.md
```

Ограничения: косвенные переходы через таблицы (switch) разрешены не все;
функции, вызываемые только косвенно и без стандартного пролога, могут быть
пропущены; оценка `low` означает возможные данные. Адрес атласа `0xFEB0C`
(A_task_table) — таблица, а не код, поэтому помечен `invalid`.

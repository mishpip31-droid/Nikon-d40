# Nikon D40 Cinema2383 EXP04 — независимый фиксированный пресет

Только D40, не D40X. Экспериментальная сборка. **Исследованием на камере не проверялась; пользователь сообщил, что EXP04 работает (v15).** Часть A не меняется. Номер B остаётся 1.11 и не подтверждает установку именно EXP04.

Файл: `D40_EXP04_RETURN_POINTER_FIX_NOT_CAMERA_TESTED.bin`.
Размер: 3 997 696 байт. SHA-256: `7adc8ac1223c84faa3d3dcdfdb2ca67c9b2ed1649098a0d794c44dbb2b29a722`.
CRC16/XMODEM: F859; остаток всего файла — 0.

**Исправление EXP04:** восстановлен возврат адреса кривой в R4 перед возвратом к штатному загрузчику. В EXP03 вместо этого передавалась структура снимка; EXP03 больше не использовать. Подробности — `../EXP03_FAILURE_RU.md`.

## Что изменилось

- Cinema2383 — отдельная восьмая строка Optimize image. Собственные фиксированные резкость Normal, насыщенность Normal, Ia (sRGB), Hue 0, авторские матрицы и тоновая кривая.
- Custom — исходный путь Nikon с исходной резервной кривой и поддержкой ранее загруженной пользовательской кривой. Его регулировки не задают параметры Cinema.
- У Cinema нет отдельного редактируемого подменю. Это готовый пресет, как Normal.
- Сохранённые значения Custom намеренно не сбрасываются. Для заводских значений выставь их вручную по пунктам ниже.
- Называть результат точным воспроизведением Kodak 2383 нельзя: аппаратный порядок цветовых операций D40 ещё не подтверждён измерениями.

## Установка

1. Сохрани фотографии с карты, полностью заряди исправный аккумулятор.
2. Скопируй **только BIN из этой папки EXP04**, переименовав копию в **BD400111.bin**. Предыдущие BIN в этом архиве исключены; использовать EXP03 нельзя.
3. Положи файл в корень карты SD, убери другие файлы обновления. ZIP на карту не нужен. Проверь отсутствие второго расширения `.bin.bin`.
4. При выключенной камере вставь карту. Включи её, открой меню настроек → «Версия ПО ПЗУ». Если предложено обновление B, подтверди его штатным способом.
5. Не выключай камеру и не извлекай карту до сообщения о завершении. Затем выключи по указанию камеры, извлеки карту, удали BIN через кардридер и включи камеру снова.

Если обновление не предлагается, зафиксируй экран. Не подменяй номера версии и не переименовывай файл в сервисный R330. Универсальный способ восстановления после неудачной записи не подтверждён.

## Включение и восстановление Custom

1. Выбери P, S, A или M.
2. Открой MENU → значок камеры → Optimize image → последняя строка **Cinema2383** → OK.
3. Для исходных значений Custom открой Optimize image → Custom и задай: Image sharpening **Auto**, Tone compensation **Auto**, Color mode **IIIa (sRGB)**, Saturation **Auto**, Hue adjustment **0°**. Нажми **Done**.
4. После Done активен обычный Custom. Для эффекта снова выбери Cinema2383.

Загруженная раньше пользовательская кривая не удаляется: Tone Auto её не выбирает. При Tone compensation → Custom снова используется штатный механизм Nikon. Не применяй общий сброс камеры ради этого теста: он затрагивает другие настройки, и все ветви reset новой сборки не проверены.

## Проверка на камере

Сохрани исходные JPEG с карты. Для сравнения поставь камеру на устойчивую опору, зафиксируй экспозицию, ISO и баланс белого, сними одну сцену:

1. Custom с указанными выше исходными значениями.
2. Cinema2383.
3. Custom с другими резкостью и насыщенностью → Done, затем снова Cinema2383. При одинаковом освещении кадр Cinema должен остаться таким же по обработке.
4. Переключись между Normal, Custom и Cinema; проверь меню, запись и просмотр каждого JPEG.
5. Дождись окончания записи, выключи/включи камеру с активным Cinema. Проверь выделение строки и снимок; повтори для Custom.

При зависании, ошибке или неожиданном цвете останови съёмочные тесты и зафиксируй экран/пару файлов. Не прерывай незавершённую запись прошивки.

Компьютерные проверки не заменяют проверку физического сохранения, перезапуска, взаимодействия с частью A и обработки пикселей ASIC. Подробности — `../INDEPENDENT_PROFILE_RU.md`.
